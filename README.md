Simple addon that allows for adding trails to your cursor in wow 1.12.
Great for people who loose track of their cursor.


use /ctr config to open the config window.

Slash commands:
/cursortrails,
/ctr,
/ctrdebug
/ctr config
Test helper: spawn a big dot in center with /ctr test
